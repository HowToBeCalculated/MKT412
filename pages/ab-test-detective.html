Instructor notes / how this draft works

Conversions are independent Bernoulli draws using a fixed scenario seed. Observed rate = conversions ÷ visitors. Each version's approximate 95% Wilson interval uses z = 1.96. These are fixed-sample intervals, not sequential stopping boundaries; repeatedly checking and choosing a stopping time requires a suitable analysis plan. Interval overlap alone is not a formal test of the difference between versions.

At the planned finish, this draft reports the observed result and the hidden scenario rates; it does not declare statistical significance. For the interval formula, see NIST's binomial confidence interval guide.

Extension idea: ask students to choose a minimum useful effect, a sample-size plan, and a business metric before collecting data.
